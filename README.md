# Chatify

## About
A dynamic web application that enables users to connect, share, and interact seamlessly. Users can search and add friends, create posts, comment, react to content, view friends' updates, and chat in real-time.

---

## Features

- **User Connections:**  
  Easily search for and add friends to build your network.

- **Content Sharing:**  
  Create and share posts with support for images and multimedia via Cloudinary.

- **Engagement Tools:**  
  Comment on posts and add reactions to express your thoughts.

- **Real-Time Chat:**  
  Enjoy live, real-time conversations with your friends using Socket.io.

- **Responsive Interface:**  
  An intuitive, modern UI built with React for seamless user experience.

---

## Technology Stack

- **Frontend:** React
- **Backend:** Node.js, Express.js
- **Real-Time Communication:** Socket.io
- **Media Management:** Cloudinary
- **Database:** MongoDB
